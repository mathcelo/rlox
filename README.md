# rlox

A Rust implementation of the Lox programming language, following [Crafting Interpreters](https://craftinginterpreters.com/) by Robert Nystrom.

This project is my attempt to learn Rust and review interpreter implementation techniques to improve my understanding of program analysis and static analysis.

## Building and Running

```bash
# Build
cargo build

# Run REPL
cargo run

# Execute a file
cargo run path/to/script.lox
```
